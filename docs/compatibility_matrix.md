## Поля POST /v1/responses

| Поле / режим | Статус | Поведение / тест |
|---|---|---|
| `model` | ✅ | валидация по схеме, проксирование |
| `instructions` | ✅ | анонимизируется вместе с input |
| `input` — строка | ✅ | анонимизируется, e2e |
| `input` — массив сообщений (`user`/`assistant`/`system`/`developer`) | ✅ | текстовые части анонимизируются |
| `input[].content[].type=input_text` | ✅ | основная текстовая часть |
| `input[].content[].type=input_file` (inline `file_data`, data URI) | ✅ TXT/DOCX | декодирование и извлечение текста внутри сервиса |
| `store=false` | ✅ | значение по умолчанию |
| `store=true` | 🚫 | 400: «не хранит состояние, история — явно в input» |
| `stream=false` | ✅ | обычный JSON-ответ |
| `stream=true` | ⏳ неделя 4 | пока 501 not_implemented |
| `tools[].type=function` (одна тестовая функция) | ⏳ неделя 5 | схема принимается, цикл в разработке |
| `tools[].type`≠function (`web_search` и пр.) | 🚫 | 400: «только function» |
| `previous_response_id` | 🚫 | 400: поле вне профиля |
| `conversation` (Conversations API) | 🚫 | 400: поле вне профиля |
| `background` | 🚫 | 400: поле вне профиля |
| `file_id` / `file_url` в частях | 🚫 | 400: поле вне профиля |
| `input[].content[].type=input_image` и прочие | 🚫 | 400: «разрешены input_text и input_file» |
| Непрозрачные/неизвестные поля | 🚫 | 400 (extra=forbidden), без пропуска |
| WebSocket, фоновые режимы | 🚫 | вне профиля эндпоинта |

## Форматы input_file

| Формат | Статус | Поведение |
|---|---|---|
| TXT: UTF-8 (BOM/без), UTF-16 LE/BE | ✅ | текст извлекается |
| TXT: CP1251 | ✅ | запасной вариант кодировки |
| DOCX (OOXML) | ✅ | параграфы + таблицы; метаданные не читаются |
| PDF / DOC / RTF / изображения / без расширения | 🚫 | 400 до модели: «разрешены TXT и DOCX» |
| MIME вне `text/*`, docx, octet-stream | 🚫 | 400: тип содержимого не поддерживается |
| Имя с путём (`../x.txt`) | 🚫 | 400 |
| Размер > `ANONGW_MAX_FILE_MB` (10 МБ) | 🚫 | 400 |
| `file_data` не base64 | 🚫 | 400 |

## Безопасность профиля

| Проверка | Статус |
|---|---|
| `Authorization: Bearer <ключ сервиса>` обязателен | ✅ 401 иначе |
| Исходные ПДн отсутствуют в запросе к модели | ✅ e2e-тест перехватом mock |
| Имя файла и метаданные не пересылаются модели | ✅ e2e-тест |
| Изоляция пользователей (`X-Anongw-User`) | ✅ отдельные контексты |

## Режимы ответа

| Режим | Управление | Поведение |
|---|---|---|
| А: маркеры сохраняются | по умолчанию | ответ модели с маркерами передаётся как есть |
| Б: обратная подстановка | заголовок `X-Anongw-Restore: true` | исходные значения подставляются только в текстовые поля ответа; неизвестные маркеры не восстанавливаются |
