## Заметки недели

- Пользователь сервиса идентифицируется заголовком `X-Anongw-User`
  (по умолчанию `default`) — ключ для изоляции контекстов; ключ клиента
  проверяется по `Authorization: Bearer <SERVICE_API_KEY>`.
- Режим ответа: пока всегда «маркеры сохраняются» (режим А); переключение
  режимов и восстановление — пуш 5 (Р5).
- Unit-фикстура (`tests/conftest.py`) работает без живой модели: валидные
  запросы доходит до upstream и получают 502 — так тестируются 400-ветки.
  Полные сценарии — только integration с mock.
