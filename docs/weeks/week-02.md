# Неделя 2 — ветка `week-02`

> Спринт 1, первая половина. Цель: всё, из чего в неделе 3 собирается end-to-end
> конвейер (веха M1). Правила — [docs/git-workflow.md](../git-workflow.md).

**DoD недели:** схемы профиля зафиксированы и отклоняют неподдерживаемое до
модели; rule-детекторы строгих форматов проходят тесты; 75 примеров
генерируются с разметкой; TXT-извлечение встроено в конвейер-эскиз; хранилище
проходит через контракты; mock перехватывает и отдаёт записанные запросы.
