# Обработка файлов: поддерживаемые части и ограничения (черновик)

> Неделя 1, пуш 4 (Р4). Черновик по DoD; финализируется к неделе 8.
> Реализация: `src/anongw/files/extractor.py`.

## Что поддерживается

### TXT

- Кодировки: UTF-8 (с BOM и без), UTF-16 LE/BE (по BOM), CP1251 (запасной вариант,
  если байты не распознались как UTF-8).
- Извлекается всё содержимое как есть.

### DOCX (OOXML)

Извлекаются:

- параграфы основного текста и таблицы **в порядке следования в документе**;
- таблицы — построчно, ячейки через `"; "`, пустые ячейки пропускаются,
  объединённые ячейки не дублируются (согласовано в пуше 4 недели 4).

Не извлекается (намеренно):

- метаданные документа (автор, даты, комментарии, свойства) — не читаем вовсе,
  наружу не уходят;
- колонтитулы, сноски, примечания;
- надписи и фигуры (shapes), текстовые рамки;
- встроенные объекты и вложения;
- текст на изображениях (OCR — расширение по ТЗ);
- URL-адреса гиперссылок (текст ссылки сохраняется, сам адрес теряется).

## Валидация (отказ ДО обращения к модели)

| Проверка | Поведение |
|---|---|
| Имя файла отсутствует | понятная ошибка: формат определяется по имени |
| Имя содержит путь (`/`, `\`) | понятная ошибка |
| Расширение не `.txt`/`.docx` (PDF, DOC, RTF, изображения, без расширения) | понятная ошибка |
| `file_data` не является base64 | понятная ошибка |
| Размер декодированных данных > `ANONGW_MAX_FILE_MB` (по умолчанию 10) | понятная ошибка |
| DOCX повреждён или не читается | понятная ошибка |
| Текст извлечён пустым | понятная ошибка |
